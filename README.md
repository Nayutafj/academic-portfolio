## 项目经历

### 无人机集群自主导航避障及路径规划研究

**大一年度项目｜项目负责人｜指导教师：包俊老师**

项目围绕多架无人机在有障碍物的环境中如何安全、协同地到达目标展开。研究从二维仿真入手，再尝试向三维环境扩展。

- **二维复现与测试：**阅读并梳理 [浙江大学 ZJU-FAST-Lab](https://github.com/ZJU-FAST-Lab) 的相关开源工作，学习多无人机路径规划和避障的实现思路；在二维仿真中复现协同避障与路径规划实验，并在 Ubuntu 和 Windows 环境中部署、测试。
- **三维方案探索：**最初尝试利用 Arma 3 的场景图像构建三维环境信息，但从 RGB 图像实时恢复可靠点云存在精度和计算开销问题。随后转向 Unity 仿真环境，使用虚拟深度摄像头获取深度图，再通过坐标变换生成三维点云。
- **阶段性成果：**在二维环境中完成多无人机协同避障相关实验；在 Unity 中完成单架无人机基于深度信息的初步三维导航与避障验证。三维集群协同是后续可继续扩展的方向。

## 竞赛经历

### 2026 年美国大学生数学建模竞赛（MCM）

**C 题｜Successful Participant（S 奖）｜队号：2621535**

论文 *Balancing Act: A Quantitative Study of Judge-Audience Dynamics and a Novel Scoring System for Dancing with the Stars* 研究节目中评委评分和观众投票如何共同影响淘汰结果。由于观众投票数未公开，论文先根据历史评分和淘汰记录反推投票比例，再比较不同赛制的影响。

- 针对百分比制和排名制，分别建立线性规划与混合整数线性规划模型，估计观众投票。
- 使用敏感性分析、Bootstrap 和统计检验检查估计与赛制比较结果，并用回归分析研究选手特征的影响。
- 在此基础上设计动态贝叶斯评分方案，通过历史赛季回测比较不同评分机制。

### 2026 年全国大学生数学建模竞赛

**广东赛区本科组二等奖（获奖名单初稿）｜名单序号：1113｜报名号：202619060158**

论文《有界误差测向下无线电干扰源的鲁棒定位与滚动清除》研究机器狗在测向误差、接收范围不确定和多频道干扰源并存的条件下，如何保证发现、定位并清除干扰源，同时尽量缩短行动时间。

- 将第二次测向位置建模为最坏情形下的优化问题，比较不同测点的定位效果。
- 针对多频道搜索设计确定性覆盖和滚动路径规划方案，并通过仿真实验检验。
- 在定向干扰源场景中进一步考虑辐射方向，设计相应的覆盖布局。
